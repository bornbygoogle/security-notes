# PT1 Penetration Test Report — Template

> **How to use this:** copy this file per engagement (`cp report-template.md my-report.md`). Fill it as you work, not at the end. On the real exam you'll transcribe these fields into TryHackMe's in-environment reporting app (dropdowns + text fields) — so keeping your notes in this shape makes exam-day reporting pure data entry. Mirror the exam's own structure closely; deviating loses points.
>
> **Reminders baked in from the grading rules:** always attach the **flag** to a finding · use a **predefined category** (not a custom label) · fill **every** field · write **technical, keyword-dense** content · paste **real terminal/HTTP evidence**. Include an *initial reconnaissance* line in every write-up.
