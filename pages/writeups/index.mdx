# Write-ups

Methodology notes from rooms and labs.

> **⚠️ Before publishing a write-up here, decide what's public.**
> This site is public. Flags, passwords, admin emails, and target IPs are fine to keep in your
> **private** `.md` notes on disk, but think twice before pushing them to a public page.
> A good public write-up teaches the **method** (the *why* and the *how*) without necessarily
> handing out every answer.

## Adding a write-up

1. Create `pages/writeups/<room-name>.mdx`.
2. Add it to `pages/writeups/_meta.js` for the sidebar order, e.g.:

   ```js
   export default {
     index: 'Overview',
     'grep': 'Grep — OSINT + Web'
   }
   ```

3. `git push` → auto-deploys.
